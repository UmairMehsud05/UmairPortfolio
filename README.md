# Umair Khan — Portfolio

Modern personal portfolio for a Junior .NET Developer.

## Stack

- React + TypeScript
- Vite
- Framer Motion

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy (GitHub Pages)

1. Push this repo to GitHub.
2. Enable GitHub Pages from the `dist` folder (or use the `gh-pages` branch).
3. If the site is served from a project path (e.g. `/UmairPortfolio/`), set `base` in `vite.config.ts` accordingly.

## Customize

Edit `src/data/content.ts` for name, email, skills, projects, and social links.
